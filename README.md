# Nest Architects — website concept (unofficial)

A two-page speculative redesign concept for NEST Architects, Nagpur. It was made independently and is
**not commissioned by, affiliated with or endorsed by** the studio. The pages carry `noindex`.

- `/` — homepage
- `/work/vijayshree/` — project page

Static site built with [Astro](https://astro.build); no backend, no tracking, and the enquiry form sends nothing.

```
npm install
npm run dev      # local preview
npm run build    # static output in dist/
npm run verify   # checks pages, internal paths and noindex
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml`. See `ASSETS.md` for the source of content and assets.
